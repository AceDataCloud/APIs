# Suno Wav API Integration Instructions

SUNO allows us to obtain music in wav format files. This document explains the integration methods for the related API.

The core input parameter for this API is `audio_id`, which is the song ID generated by the official source; it also optionally supports `callback_url` for asynchronous callback addresses.

The `audio_id` we input here is `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer aa287fa4cc54401087a9fab3f99630af",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

The result is as follows:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://platform.cdn.acedata.cloud/suno/6a5a2099-d6d3-4930-9709-a30ac5dc7de5.wav"
    }
  ]
}
```

As we can see, the `file_url` field in `data` is the wav format file of the music obtained, which is a publicly accessible CDN address.

> **About WAV Link Persistence and Validity**
>
> WAV files on the upstream Suno CDN (`https://cdn1.suno.ai/{audio_id}.wav`) are only retained for a few days before being reclaimed, returning a 403 on access.
> To prevent link expiry, this API automatically copies the upstream WAV file to our own CDN (`https://platform.cdn.acedata.cloud/suno/{task_id}.wav`) before returning, so the `file_url` returned is a stable address that will not immediately expire due to upstream CDN expiry.
> **The copied link is valid for 30 days**. After 30 days, the file will be cleaned up periodically. We recommend downloading and saving it to your own storage as soon as possible.
> In the rare event of a copy failure, the API falls back to the original upstream URL, consistent with historical behavior.
