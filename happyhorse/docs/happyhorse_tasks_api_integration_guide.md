# Integration and Use of HappyHorse Tasks API

The main function of the HappyHorse Tasks API is to query the execution status of tasks by inputting the task ID generated by the HappyHorse Videos Generation API.

This document will provide detailed integration instructions for the HappyHorse Tasks API, helping you easily integrate and fully utilize the powerful features of this API. With the HappyHorse Tasks API, you can easily query the execution status of tasks from the HappyHorse Videos Generation API.

## Application Process

To use the HappyHorse Tasks API, you first need to apply for the corresponding service on the [HappyHorse Videos Generation API](https://platform.acedata.cloud/documents/happyhorse-videos) page, and then copy the task ID returned from the HappyHorse Videos Generation API.

Then, go to the [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks) page to apply for the corresponding service. After entering the page, click the "Acquire" button.

If you are not logged in or registered, you will be automatically redirected to the login page inviting you to register and log in. After logging in or registering, you will be automatically returned to the current page.

There is a free quota available for first-time applicants, allowing you to use the API for free.

## Request Example

The HappyHorse Tasks API can be used to query the results of the HappyHorse Videos Generation API. For information on how to use the HappyHorse Videos Generation API, please refer to [HappyHorse Videos Generation API Integration Guide](happyhorse_videos_api_integration_guide.md).

We will take one task ID returned by the HappyHorse Videos Generation API as an example to demonstrate how to use this API. Suppose we have a task ID: `27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1`.

### Setting Request Headers and Request Body

**Request Headers** include:

- `accept`: Specifies that the response should be in JSON format, set to `application/json`.
- `authorization`: The API key obtained after application.

**Request Body** includes:

- `id`: The task ID to query.
- `action`: The operation method for the task. Use `retrieve` to query a single task.

### Code Example

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: ******' \
-H 'content-type: application/json' \
-d '{
  "id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/happyhorse/tasks"

headers = {
    "accept": "application/json",
    "authorization": "******",
    "content-type": "application/json"
}

payload = {
    "id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

The returned result contains multiple fields, with the `request` field being the request body when the task was initiated, and the `response` field being the response body returned after the task is completed. The field descriptions are as follows:

- `id`: The ID of the video generation task, used to uniquely identify this task.
- `request`: The request information submitted when the task was created.
- `response`: The response information returned after the task is completed.

## Batch Query Operation

This is for querying the details of multiple task IDs at once. Set the `action` to `retrieve_batch` and provide an `ids` array.

**Request Body** includes:

- `ids`: An array of task IDs to query.
- `action`: Set to `retrieve_batch` for batch queries.

### Code Example

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: ******' \
-H 'content-type: application/json' \
-d '{
  "ids": ["27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1", "a1b2c3d4-e5f6-7890-abcd-ef1234567890"],
  "action": "retrieve_batch"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/happyhorse/tasks"

headers = {
    "accept": "application/json",
    "authorization": "******",
    "content-type": "application/json"
}

payload = {
    "ids": ["27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1", "a1b2c3d4-e5f6-7890-abcd-ef1234567890"],
    "action": "retrieve_batch"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Error Handling

When calling the API, if an error occurs, the API will return the corresponding error code and message. For example:

- `400 token_mismatched`: Bad request, the specified token is not matched with the API.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `500 api_error`: Internal server error.

### Error Response Example

```json
{
  "error": {
    "code": "invalid_token",
    "message": "The specified token is invalid or wrong."
  },
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```
