## Overview

The SeeDream Images Generation API generates official images of ByteDance Seedream by inputting custom parameters such as prompt, model, size, and optional reference images.

The SeeDream Tasks API queries the execution status of tasks by inputting the task ID generated by the SeeDream Images Generation API.

## Application Process

To use the SeeDream Images Generation API, first open the [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) and copy your API Token.

A single API Token works across every service on the platform — no need to subscribe per service. New accounts receive free starter credit; when it runs low you can top up your shared balance in the console.

## Quick Start

- Base URL: [https://api.acedata.cloud](https://api.acedata.cloud)
- Service page: [SeeDream Image Generation on Ace Data Cloud](https://platform.acedata.cloud/service/seedream)
- Docs: [Developer documentation](https://docs.acedata.cloud)

```bash
curl -X POST 'https://api.acedata.cloud/seedream/images' \
  -H 'accept: application/json' \
  -H 'authorization: ******' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "doubao-seedream-5.0-lite",
    "prompt": "a white siamese cat"
  }'
```
