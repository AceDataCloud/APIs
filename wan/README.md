## Get your Ace Data Cloud API key

1. Open [Ace Data Cloud → Applications](https://platform.acedata.cloud/console/applications?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=wan_api_readme_api_key). Sign in, or register an account first.
2. Find **General application**. If it has not been created, choose **Initialize General Application**. A general key can use the services available to your account; a dedicated application's key is limited to its service. Check the required service/model access and [current pricing](https://platform.acedata.cloud/models?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=wan_api_readme_pricing).
3. Copy the **API Key** from the application card, or open **Keys / Manage Keys → Create** to create a separate key for this integration. Give it a recognizable name so you can revoke or rotate it independently.
4. When creating a key, review **Expiration Time**, **Set Usage Limitation**, and **Allowed APIs**. Enable only the restrictions you need, allow the operations you will call, then click **Create** and copy the token from the key list. Task lookup does not grant permission to submit a generation. Confirm the application's balance can cover your first request; any trial allowance is whatever your account currently displays.
5. Copy only the token value, without quotation marks, spaces, or `Bearer `. An API Key / API Token field expects this raw value; only a manually configured HTTP `Authorization` header needs the `Bearer ` prefix. A `platform-...` account-management token cannot replace a generation API key.

Save the key in the client's credential store or the environment variable shown below. Never put it in a prompt, shared workflow, screenshot, or Git commit. If authentication fails, check the full copied value, application/service access, expiration, usage limit, and balance before creating another key.

## Overview

The Wan Videos Generation API generates official videos of Tongyi Wanxiang by inputting custom parameters such as prompt, action, model, and optional reference images or videos.

The Wan Tasks API queries the execution status of tasks by inputting the task ID generated by the Wan Videos Generation API.

## Application Process

To use the Wan Videos Generation API, apply for the corresponding service on the [Wan Videos Generation API](https://platform.acedata.cloud/documents/52b0f490-1bbf-4fe5-b60e-96626d333d2c?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=wan_api_readme_documents_52b0f490_1bbf_4fe5_b60e_96626d333d2c) page. ## Quick Start

- Base URL: [https://api.acedata.cloud](https://api.acedata.cloud)
- Service page: [Wan Video Generation on Ace Data Cloud](https://platform.acedata.cloud/services/f35a16da-726b-425f-96ba-bec7436cfc23?utm_source=github&utm_medium=referral&utm_campaign=evergreen&utm_content=wan_api_readme_service_wan)
- Docs: [Developer documentation](https://docs.acedata.cloud)

```bash
curl --request POST "https://api.acedata.cloud/wan/videos" \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "action": "text2video",
    "model": "wan2.6-t2v",
    "prompt": "Astronauts shuttle from space to volcano",
    "duration": 5
  }'
```
