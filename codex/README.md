## Why Use Codex on Ace Data Cloud

- Unified developer platform with one API key, billing system, and usage tracking
- Production-ready OpenAI-compatible API endpoints served from [https://api.acedata.cloud](https://api.acedata.cloud)
- English integration guides and service documentation
- Lower-cost Codex CLI and VS Code extension access through Ace Data Cloud's `/v1/responses` compatible interface

## Overview

Codex CLI is an open-source local programming agent from OpenAI. It can read code, modify files, run commands, and assist with development tasks. Ace Data Cloud provides OpenAI Responses-compatible proxy access so Codex can use Ace Data Cloud credentials.

## Application Process

To use Codex with Ace Data Cloud, visit the [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) to obtain an API Token. First-time applicants receive free credits.
