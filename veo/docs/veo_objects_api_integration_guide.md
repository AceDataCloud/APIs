# Veo Objects API Retirement Notice

The `/veo/objects` endpoint has been retired and is no longer available for new requests. This page remains as a compatibility notice for existing documentation links.

Use the [Veo Videos Generation API Integration Guide](veo_videos_generation_api_integration_guide.md) to create videos and the [Veo Tasks API Integration Guide](veo_tasks_api_integration_guide.md) to retrieve asynchronous task results.
