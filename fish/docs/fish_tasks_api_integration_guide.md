# Fish Tasks API Integration Guide

The Fish Tasks API (`POST /fish/tasks`) allows you to query the execution status of tasks generated by the [Fish Audios Generation API](fish_audios_generation_api_integration_guide.md).

## Application

To use the Fish Tasks API, first visit the [Fish Audios Generation API](https://platform.acedata.cloud/documents/e681b715-54fd-4464-a59a-d7f14500e095) page to apply for the service and copy the task ID generated by that API:

<p><img src="https://cdn.acedata.cloud/jxvue8.png" width="500" class="m-auto"></p>

Then visit the [Fish Tasks API](https://platform.acedata.cloud/documents/44c93949-1419-4a45-8db5-8a8335de7151) page and click the "Acquire" button to obtain your credentials:

![Application Page](https://cdn.acedata.cloud/rci31i.png)

If you are not logged in or registered, you will be automatically redirected to the login page. After logging in, you will be returned to the current page.

First-time applicants receive a free quota to try the API at no charge.

## Request Example

The Fish Tasks API can be used to query the results of the Fish Audios Generation API. For information on how to use the Fish Audios Generation API, please refer to the [Fish Audios Generation API Integration Guide](fish_audios_generation_api_integration_guide.md).

We will use a task ID returned by the Fish Audios Generation API as an example. Suppose we have a task ID: `2725a2d3-f87e-4905-9c53-9988d5a7b2f5`.

### Setting Request Headers and Request Body

**Request Headers** include:

- `accept`: Specifies that the response should be in JSON format, set to `application/json`.
- `authorization`: The API key, selected after application.

**Request Body** includes:

- `id`: The task ID to query.
- `action`: The operation method for the task (use `retrieve` for a single task).

<p><img src="https://cdn.acedata.cloud/xc5ejq.png" width="500" class="m-auto"></p>

### Code Example

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/fish/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/fish/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Batch Query Operation

To query multiple task IDs at once, set `action` to `retrieve_batch` and use `ids` (an array) instead of `id`.

**Request Body** includes:

- `ids`: An array of task IDs to query.
- `action`: The operation method for the task (`retrieve_batch`).

### Code Example

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/fish/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["2725a2d3-f87e-4905-9c53-9988d5a7b2f5", "3836b3e4-g98f-5016-ad64-aa99e6b8c3g6"],
  "action": "retrieve_batch"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/fish/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ids": ["2725a2d3-f87e-4905-9c53-9988d5a7b2f5", "3836b3e4-g98f-5016-ad64-aa99e6b8c3g6"],
    "action": "retrieve_batch"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Error Handling

When calling the API, if an error occurs, the API will return the corresponding error code and message. For example:

- `400 token_mismatched`: Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`: Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`: Too many requests, you have exceeded the rate limit.
- `500 api_error`: Internal server error, something went wrong on the server.

### Error Response Example

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
