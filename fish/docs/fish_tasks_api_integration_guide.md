# Fish Tasks API Integration Guide

The Fish Tasks API allows you to query the execution status of audio generation tasks by providing a task ID generated by the Fish Audios Generation API.

This document details the Fish Tasks API integration guide to help you easily integrate and fully leverage the API's capabilities. Through the Fish Tasks API, you can easily query the execution status of Fish Audios Generation API tasks.

## Application Process

To use the Fish Tasks API, first apply for the service on the [Fish Audios Generation API](https://platform.acedata.cloud/documents/e681b715-54fd-4464-a59a-d7f14500e095) page and copy the task ID from the Fish Audios Generation API, as shown below:

<p><img src="https://cdn.acedata.cloud/jxvue8.png" width="500" class="m-auto"></p>

Then go to the [Fish Tasks API](https://platform.acedata.cloud/documents/44c93949-1419-4a45-8db5-8a8335de7151) page and click the "Acquire" button, as shown below:

![](https://cdn.acedata.cloud/rci31i.png)

If you have not logged in or registered, you will be automatically redirected to the [login page](https://platform.acedata.cloud). After logging in, you will automatically return to the current page.

Upon your first application, there will be a free quota provided, allowing you to use the API for free.

## Request Example

The Fish Tasks API can be used to query the result of a Fish Audios Generation API task. For more on how to use the Fish Audios Generation API, refer to the [Fish Audios Generation API Integration Guide](fish_audios_api_integration_guide.md).

Using a task ID returned by the Fish Audios Generation API as an example, we demonstrate how to use this API. Assume we have a task ID: `2725a2d3-f87e-4905-9c53-9988d5a7b2f5`.

### Task Example

<p><img src="https://cdn.acedata.cloud/jxvue8.png" width="500" class="m-auto"></p>

### Setting Request Headers and Body

**Request Headers** include:

- `accept`: Specifies receiving JSON format responses, set to `application/json`.
- `authorization`: The API key, which can be selected after application.

**Request Body** includes:

- `id`: The task ID to query.
- `action`: The action to perform on the task.

Configuration as shown below:

<p><img src="https://cdn.acedata.cloud/xc5ejq.png" width="500" class="m-auto"></p>

### Code Examples

Various language code samples are automatically generated on the right side of the page, as shown below:

<p><img src="https://cdn.acedata.cloud/851zv2.png" width="500" class="m-auto"></p>

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/fish/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
  "action": "retrieve"
}'
```

## Batch Query

You can query multiple task IDs at once by setting the `action` to `retrieve_batch`.

**Request Body** includes:

- `ids`: An array of task IDs to query.
- `action`: The action to perform on the tasks.

Configuration as shown below:

<p><img src="https://cdn.acedata.cloud/64lid9.png" width="500" class="m-auto"></p>

### Code Examples

Various language code samples are automatically generated on the right side of the page, as shown below:

<p><img src="https://cdn.acedata.cloud/ezkzmw.png" width="500" class="m-auto"></p>

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/fish/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["2725a2d3-f87e-4905-9c53-9988d5a7b2f5","2725a2d3-f87e-4905-9c53-9988d5a7b2f5"],
  "action": "retrieve_batch"
}'
```

- `count`: The number of tasks in this batch query.

## Error Handling

When calling the API, if an error is encountered, the API will return the corresponding error code and message. For example:

- `400 token_mismatched`: Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`: Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`: Too many requests, you have exceeded the rate limit.
- `500 api_error`: Internal server error, something went wrong on the server.

### Error Response Example

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
