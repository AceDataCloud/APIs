# Grok Tasks API Integration Guide

The main function of the Grok Tasks API is to query the execution status and results of tasks by inputting the task ID generated by the Grok Videos API.

This document will provide a detailed description of the Grok Tasks API integration, helping you easily integrate and fully utilize the powerful features of this API.

## Application Process

To use the Grok Tasks API, you first need to apply for the corresponding service on the [Grok Videos API](https://platform.acedata.cloud/documents/faf08b59-36aa-4d26-b5d9-a18f113cc2be) page and obtain a task ID from the Grok Videos API.

If you are not logged in or registered, you will be automatically redirected to the login page inviting you to register and log in. After logging in or registering, you will be automatically returned to the current page.

There is a free quota available for first-time applicants, allowing you to use this API for free.

## Request Parameters

- `id`: The task ID to query (for a single task).
- `ids`: An array of task IDs to query (for batch queries).
- `action`: The operation to perform. Supported values:
  - `retrieve` (default) — retrieve a single task by `id`.
  - `retrieve_batch` — retrieve multiple tasks by `ids`.

## Single Task Query

### Code Example

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: ******' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/grok/tasks"

headers = {
    "accept": "application/json",
    "authorization": "******",
    "content-type": "application/json"
}

payload = {
    "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Response Example

Upon a successful request, the API returns the details of the video task:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "model": "grok-imagine-video-1.5-fast",
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "duration": 6
  },
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

The returned fields are:

- `id`: The ID of the video generation task, used to uniquely identify this task.
- `request`: The request parameters that were submitted when the task was created.
- `response`: The response returned after the task completed, with the same structure as the direct response from the Grok Videos API.

## Batch Task Query

To query multiple tasks at once, set `action` to `retrieve_batch` and provide an array of task IDs in the `ids` field:

### Code Example

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: ******' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea", "c7865e18-43dc-4718-9ed8-1ea090fcb7fb"],
  "action": "retrieve_batch"
}'
```

## Error Handling

When calling the API, if an error occurs, the API will return the corresponding error code and message. For example:

- `400 token_mismatched`: Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `500 api_error`: Internal server error, something went wrong on the server.

### Error Response Example

```json
{
  "error": {
    "code": "token_mismatched",
    "message": "The specified token is not matched with API."
  },
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```
