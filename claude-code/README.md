## Why Use Claude Code on Ace Data Cloud

- Unified developer platform with one API key, billing system, and usage tracking
- Production-ready Claude-compatible endpoints served from [https://api.acedata.cloud](https://api.acedata.cloud)
- Integration guides for terminal, IDE, desktop, and GitHub workflows
- Lower-cost Claude Code access through the Ace Data Cloud proxy

## Overview

Claude Code is Anthropic's agentic coding assistant. On Ace Data Cloud, you can configure Claude Code to use your Ace Data Cloud credentials instead of the default Anthropic setup, so the same account can power Claude Messages API usage and Claude Code integrations.

## Application Process

To use Claude Code with Ace Data Cloud, first open the [Claude Messages service page](https://platform.acedata.cloud/documents/claude-messages) and click **Acquire** to get your credentials.

A free quota is available for first-time applicants, so you can try the integration before topping up.
