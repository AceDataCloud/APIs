## Overview

Claude Code is Anthropic's programming AI agent that can be used in terminals, IDEs (VS Code, JetBrains, Cursor), and CI/CD pipelines (GitHub Actions). By using the AceData Cloud proxy, you can access Claude Code at a lower cost without an official Anthropic subscription.

## Application Process

To use the Claude Code service, apply for the corresponding credentials on the [Claude Messages service page](https://platform.acedata.cloud/documents/claude-messages). After entering the page, click the "Acquire" button.

There is a free quota available for first-time applicants, allowing you to use this API for free.

## Quick Start

- Base URL: [https://api.acedata.cloud](https://api.acedata.cloud)
- Service page: [Claude Code on Ace Data Cloud](https://platform.acedata.cloud/documents/claude-messages)
- Docs: [Developer documentation](https://docs.acedata.cloud)

Configure your environment to use the AceData Cloud proxy:

```bash
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```
