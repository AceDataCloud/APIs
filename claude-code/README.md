## Overview

Claude Code is an Agentic Coding tool launched by Anthropic that can be used in various environments such as terminals, IDEs, and desktop applications. It autonomously reads codebases, edits across files, runs terminal commands, and completes complex programming tasks. By using the AceData Cloud proxy, you can use Claude Code at a lower cost with a unified API key.

## Application Process

To use Claude Code, apply for the corresponding service on the [Claude Messages service page](https://platform.acedata.cloud/documents/claude-messages). After entering the page, click the "Acquire" button.

There is a free quota available for first-time applicants, allowing you to use this service for free.

## Quick Start

- Base URL: [https://api.acedata.cloud](https://api.acedata.cloud)
- Service page: [Claude Code on Ace Data Cloud](https://platform.acedata.cloud/service/claude)
- Docs: [Developer documentation](https://docs.acedata.cloud)

```bash
export ANTHROPIC_AUTH_TOKEN="YOUR_API_TOKEN"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
claude
```
