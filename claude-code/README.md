## Why Use Claude Code on Ace Data Cloud

- Unified developer platform with one API key, billing system, and usage tracking
- Production-ready AI API endpoints served from [https://api.acedata.cloud](https://api.acedata.cloud)
- English integration guides and service documentation
- Lower-cost Claude Code access for terminals, IDEs, and CI/CD workflows

## Overview

Claude Code is a programming AI agent from Anthropic that can be used in terminals, IDEs, and CI/CD pipelines. With the Ace Data Cloud proxy, you can configure Claude Code to use Ace Data Cloud credentials and shared platform credits.

## Application Process

For first-time applicants, visit the [Claude Messages service page](https://platform.acedata.cloud/documents/claude-messages) and click "Acquire" to get credentials and receive free credits.
