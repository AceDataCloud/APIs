## Why Use hCaptcha on Ace Data Cloud

- Unified developer platform with one API key, billing system, and usage tracking
- Production-ready API endpoints served from [https://api.acedata.cloud](https://api.acedata.cloud)

## Overview

The hCaptcha APIs recognize challenges, obtain tokens, and retrieve asynchronous task results.

## Application Process

Obtain an API Token from the [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications). One token can call every service on the platform.
