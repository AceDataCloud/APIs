# Dreamina Video Generation API

Dreamina AI video generation and asynchronous task retrieval through Ace Data Cloud.

## Quick Start

- Base URL: [https://api.acedata.cloud](https://api.acedata.cloud)
- Service page: [Dreamina on Ace Data Cloud](https://platform.acedata.cloud/service/dreamina)
- Authentication: pass your API token in the `Authorization` header

## APIs and Guides

| API | Path | Integration Guidance |
| --- | --- | --- |
